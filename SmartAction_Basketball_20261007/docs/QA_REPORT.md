# 驗證結果與實際限制

驗證日期：2026-10-07。程式來源為本附件原創 HTML／CSS／JavaScript。

## 15 項模擬核心測試通過

執行 `node tests/core.test.cjs`，驗證六位球員與初始球權、30 秒種子重現、移動正規化與球場邊界、跳躍與手腿方向獨立、指定方向傳球、三分出手與計分、200 個相同種子的正反瞄準成功率比較、灌籃事件、飛行快照還原、快照隔離與無效輸入、進攻時間轉換、事件佇列上限、完整三分鐘比賽結束及無效時間步長。

## 29 項真實瀏覽器互動測試通過

使用 Linux Chromium，桌面視窗和手機視窗模擬。由实际 DOM、鍵盤與 Pointer Events 操作遊戲；未替換遊戲物理或繪圖結果。

## 未驗證或未提供

- 未測試實體 iPhone／iPad 的 Safari、實體 Android、各種舊型 iPod 或全部硬體；手機模擬不等於這些真實裝置驗證。
- 定位測試使用瀏覽器提供的模擬高雄座標，沒有宣稱驗證真實 GPS 精度、Google 球場地點完整性或交通狀況。
- 低資源測試模擬瀏覽器資源提示，沒有宣稱等同真實低記憶體、過熱或低電量手機壓力測試。
- 未做十萬人並發或 CDN 壓力測試，沒有即時真人房間後端；訪客各自在本機與 AI 遊玩。
- 本包沒有 Maps Embed key，未測試啟用 key 的正式 Google Embed／Places 呼叫；基本版定位與 Maps 外開網址已驗證。
- 沒有代替使用者推送 GitHub repository 或修改 SmartAction 上線網站。

## 容量測量

版本建置的十個 runtime 檔合計約 230 KB（未壓縮原始檔）。獨立 HTML 約 275 KB，包含完整程式和內嵌可下載教學。22 份語言入口 HTML 合計約 321 KB，只有開啟相應頁面時才需要該份 HTML；共同資源可快取。

若粗略按 runtime 原始檔 230 KB × 十萬位首次訪客估算，約 23 GB；這是檔案大小算術，不是實際網路測量，也不是主機並發容量保證。HTTP 壓縮、快取、重試、service worker 首次下載和主頁、地圖等外部請求都會改變傳輸量。
