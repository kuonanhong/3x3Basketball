聰動 AI 教練：真正的瀏覽器 CPU 生成

本版附上 Qwen2.5-0.5B-Instruct 的 ONNX q8 權重、分詞器、Transformers.js 3.8.1 及 ONNX Runtime Web。按下「載入 AI 教練」後，模型才會下載到使用者裝置並執行；不需要 API 金鑰或付費推論服務。GitHub Pages 提供檔案，計算發生在觀看者的 CPU。

這是依多語、免費授權與瀏覽器 CPU 資源做的折衷選擇，不能宣稱是所有模型中「最準」的模型。0.49B 小模型可能答錯、混用簡繁體或忽略部分指令；輸出是遊戲練習提示，不代表球員官方能力評分或醫療建議。

〇、v7 說明

v7 套件為縮小附件不含 16 塊權重（512,096,557 bytes）。GitHub 上既有的 v6 權重會由上傳腳本逐塊 SHA-256 驗證後沿用；本機請用 python3 tools/fetch_model.py --from "v6 的 SmartAction_Sports 資料夾" 或 --download 準備。教練提示詞已擴充為 30 種模式並加入本場數據，以學徒問答為框架；回答仍為小模型品質。

為何不是 q4？此固定 ONNX 版本的 q4 包含未壓縮到 4-bit 的其他張量，整個檔案約 786 MB，反而比 q8 的 512 MB 大。q4f16 約 483 MB，但 FP16 算子在各瀏覽器 CPU 的支援與速度不盡相同，因此使用 q8。

二、有網路與離線用法

  1. GitHub Pages：先開網站，再手動載入模型。第一次需傳輸約 547 MB（模型、分詞器及執行套件）。一般遊戲不必先下載模型。
  2. 同一裝置再次載入：分塊會嘗試保存在瀏覽器 Cache Storage。瀏覽器配額不足、無痕模式或清除網站資料會使快取失效；不要把瀏覽器快取當成永久備份。
  3. 保證檔案在手上的離線方法：完整解壓縮附件，在網站根目錄啟動本機 HTTP 伺服器，再斷網使用。需保留完整 models/ 與 vendor/。
cd "/你的解壓縮路徑/SmartAction_Sports"
python3 -m http.server 8080 --bind 127.0.0.1
# 開啟 http://127.0.0.1:8080/

直接雙擊 index.html 的 file:// 路徑不能可靠啟動模組 Worker。使用 HTTPS 的 GitHub Pages 或 localhost 即可。手機記憶體有限時可使用基本教練；基本教練是已寫好的多語提示，清楚標示為非生成式 AI。載入模型可能使用超過 1 GB RAM；無法保證每一支手機都能執行。

三、下載完整性與取消

models/qwen2.5-0.5b/onnx/model_quantized.onnx.parts.json 記錄每塊大小與 SHA-256。Worker 逐塊驗證並串成模型供 WASM 使用。原檔完整 SHA-256：

41834041ab1b29eff9fc592f1a29a1844133aea35832ea9fa91682be13016100

取消會終止 Worker 並釋放模型，遊戲主執行緒不等待生成結束。下次提問需重新載入模型；已成功快取的分塊可重用。完整性錯誤時會清掉該塊快取，重新載入即可重新取得檔案。遊戲與 AI 同時執行仍會共用 CPU，低階裝置建議先暫停練習再問問題。
