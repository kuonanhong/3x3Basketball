1. 第一次開啟

  1. 解壓縮 SmartAction_Sports_v6_FullPackage.zip，進入 SmartAction_Sports 資料夾，找到含 index.html、models/、vendor/、assets/ 的專案目錄。
  2. 在終端機切換到該目錄，執行以下指令，並保持終端機開著。
cd "/你的解壓縮路徑/SmartAction_Sports"
python3 -m http.server 8080 --bind 127.0.0.1

也可在 Mac／Linux 執行 bash Start_Local.sh，Windows 執行 Start_Local.bat。這兩個啟動器同樣需要已安裝 Python，並啟動本機 HTTP 服務。

瀏覽器開啟 http://127.0.0.1:8080/。要停止伺服器，在終端機按 Control + C。上方路徑是範例，請換成實際位置；可輸入 cd 後將資料夾拖入終端機。

  1. 選擇「運動」、級別與視角，按「開始比賽」。一般遊戲不用先載入 AI 模型。
  2. 先選輕鬆難度，熟悉移動、瞄準和蓄力後，再提高難度。
  3. 按「開啟音效」啟用原創合成音效與加油氣氛。瀏覽器通常需要一次使用者點擊才能播放聲音。
GitHub Pages 使用 HTTPS，可直接開網站。直接雙擊 index.html 的 file:// 開法無法可靠使用 Worker、模型下載、快取與定位；需要本機 HTTP 或正式 HTTPS 網址。

macOS、Windows、Linux 電腦及 iOS／Android 手機平板使用同一套網頁；實際速度仍取決於瀏覽器、CPU、記憶體和電池限制。本版不是每個型號皆經實機驗證的保證。

3. 本版實際提供的 16 種練習

各項使用原創、簡化的練習規則。雙打及團體項目的其他球員由本機程式控制；「多人在同一網址各自玩」與「網路真人同場對戰」不同，本版沒有網路同步真人比賽。

模式主要練習範圍
1. 3×3 籃球運球、傳球、蓄力出手、防守與重播。娛樂版兩分／三分計分，並非完整 FIBA 3×3 規則。
2. 5×5 足球持球移動、傳球、射門與球門判定。簡化足球練習，未完整實作職業犯規、越位與聯賽賽制。
3. 棒球打擊投球時機、擊球點、方向、轉腰與肩部控制。距離／擊球評分練習，不是九局完整棒球賽。
4. 羽球單打站位、越網及連續回擊。簡化回合及落地判定。
5. 羽球雙打雙人隊伍配合與站位。隊友與對手由本機 AI 控制。
6. 桌球單打瞄準、擊球與彈跳節奏。簡化桌球場面，非完整專業旋轉物理。
7. 桌球雙打隊伍配合與連續回擊。不等同全部正式輪流擊球與發球規則。
8. 網球單打移動、越網、反彈及擊球方向。練習計分，不是完整盤／局賽制。
9. 網球雙打雙人隊形與來球處理。本機 AI 配合，不是兩位遠端玩家。
10. 美式足球持球推進、傳球及達陣。簡化五人進攻練習，未完整實作 NFL 規則。
11. 冰球滑行、傳球與射門。簡化冰面慣性及球門判定。
12. 橄欖球持球推進、向後傳球及達陣。簡化練習，非完整十五人或七人賽制。
13. 排球越網、接球與站位。三人練習場景，不是完整職業六人制。
14. 手球傳球、移動與射門。四人練習隊形及簡化守門。
15. 短跑前進與交替節奏。搭配向前移動，交替 J 與 K 放開動作建立節奏；不是生物力學測量。
16. 射箭方向、高度、蓄力與命中環數。簡化風偏與標靶；J 重設瞄準。

本版已擴充以上項目；並未宣稱已完成全部奧運項目、各國職業聯盟、官方球場或所有名人堂球員。

有網路與離線兩種用法

  • 網站有網路：一般遊戲直接使用；有需要再載入 AI。模型會嘗試保存於瀏覽器快取，之後可重用。
  • 準備離線核心：按「準備離線」保存遊戲資源；模型需另外手動載入。瀏覽器可能因配額、無痕模式或清除資料而移除快取。

9. 免費主機、容量與多人使用的界線

本版網站約 550 MB 等級，低於 GitHub Pages 已發布網站的 1 GB 限制；腳本會對最終保留內容做容量檢查。模型分塊解決單檔大小問題，不會消除網站總容量限制。

GitHub Pages 有每月約 100 GB 的軟性頻寬限制。用一次全新 AI 資源下載約 546 MB 粗估，100 GB 只相當於約 180 次完整模型下載，還未計其他網頁資源；這是體積除法的粗估，不是服務允許的固定人數。快取命中與只玩基本遊戲會使實際流量不同。

English quick start

This package contains 16 simplified local sports practice modes, 24 scenic locations, 60 athlete reference cards, 84 licensed photographs and 26 interface languages. Team members and opponents are controlled locally. It is not an online multiplayer or official league game.

  1. Extract the complete package. Open a terminal in the folder containing index.html.
  2. Run the command below and open http://127.0.0.1:8080/.
python3 -m http.server 8080 --bind 127.0.0.1

Use WASD to move and arrow keys to aim. Q jumps, E crouches, J passes, and holding/releasing K performs the main sport action. Tab switches players. In baseball, Z/C controls hip rotation and F/R adjusts shoulder angle. Touch controls sit below the game canvas. Choose third-person, close follow or first-person view; use the zoom slider or mouse wheel.

Real photographs are 2D scenic backdrops and biographical cards, not reconstructed places or licensed athlete likeness models. Avatars are generic. Game ratings are fictional presets. Each image's author, source and license is documented in Asset credits.

Location is opt-in. Google Maps links open map/search results; nearby Wikimedia photo search is not a complete court database. Interface language comes from browser preferences and manual choice, not GPS.

The optional Qwen2.5-0.5B-Instruct q8 coach includes actual model weights, tokenizer and WASM runtime. First loading its assets transfers approximately 546 MB. Inference runs on the visitor's CPU. Small-model quality is experimental; Linux/Node CPU generation has been tested, but browser WASM, Intel Mac and mobile inference have not all been verified. Basic games do not require the model.

For deployment, preview first, then publish via your existing SSH key:

bash Upload_SmartAction_Sports.sh --dry-run
bash Upload_SmartAction_Sports.sh --push

Set GitHub Pages to main / (root). The uploader deploys files at the repository root, backs up the old revision, batches changes and includes the split model files. After editing or adding files, run python3 tools/build_manifest.py before uploading. Do not put private keys or tokens in the project. See deployment details and model details.

A static browser game does not provide unlimited hosting bandwidth or a 100,000-concurrent-user guarantee. Browser caches may be evicted; keep the full package for dependable local offline access.
