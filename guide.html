v7.3 新增：3D 明星招牌動作

開啟 athletes3d.html（導覽列「3D 明星招牌動作」或先發名單球員卡的「🎬 3D 招牌動作」）。左側（手機在下方）選籃球或棒球、點選明星；畫面會播放他的招牌動作並自動 360° 環繞。拖曳可自己轉、滾輪或雙指縮放；「慢動作」選 0.5× 或 0.25×；「錄成影片」會錄下一整圈並下載 1280×720 影片。招牌動作選單也能讓同一位明星做其他動作。

人物依公開的身高、體重、體型、慣用手與背號建模，是風格化示意，不是本人肖像，也不代表球員或聯盟授權；照片只用於資料卡並標示授權。

1. 第一次開啟

  1. 解壓縮 SmartAction_Sports_v7_FullPackage.zip，進入 SmartAction_Sports。
  2. Mac／Linux 執行 bash Start_Local.sh；Windows 雙擊 Start_Local.bat（需 Python 3）。瀏覽器開 http://127.0.0.1:8080/。或直接使用 GitHub Pages：kuonanhong.github.io/3x3Basketball。
  3. 頁面載入後會先估測裝置效能（約一秒），然後在主畫面上方的選單選運動，按「開始比賽」。

請用 HTTP 伺服器或 HTTPS 開啟。以 file:// 雙擊 index.html 時，按需載入的語言字典、Service Worker 與 AI 模型 Worker 會失敗。

4. 全新打擊引擎

  1. 投手（或投球手）先準備再投球。球種：棒球快速球／曲球／滑球／變速球；壘球快速球／上飄／下墜／變速；板球快球／彈跳快球／腳邊低球／旋轉球。球路在飛行後半段才變化。
  2. 畫面上的好球帶有 3×3 格；橢圓游標是球棒擊球點，用左手移動；彩色小圈是預測落點（黃＝好球帶內、紅＝外），輕鬆難度全程顯示、一般中段後顯示、挑戰只在最後顯示；虛線時機環隨球縮小，縮到最小時就是放開的時機。
  3. 按住 K 準備（打者轉腰蓄力），球越過本壘時放開。時機誤差與位置誤差一起決定擊球品質：品質越高初速越快；球棒低於球心會打高、右手上下決定仰角；太早拉打、太晚推打，左右推桿再修正方向。
  4. Q 強力揮棒：窗口小但距離遠（全壘打需要）；E 穩定揮棒：窗口大但距離短；J 觸擊。
  5. 守備員有反應時間，接殺機率依難度與防守值；結果：一／二／三壘安打（1／2／3 分）、全壘打（4 分，越過全壘打牆）、飛球／平飛／滾地出局、界外（兩好球後不算）、好球、壞球、四壞保送（1 分）、三振；三出局換局。板球：以距離得 1–3 分，碰到邊界 4 分、飛越 6 分；揮空且球擊中三柱門或被接殺即出局；每 6 球一輪。

畫面上方顯示壞球／好球／出局／局與球種球速（板球：得分／三柱門／輪／球數）；擊球後顯示初速、仰角、距離與「太早／太晚／完美」。顯示數字為遊戲單位換算的示意值，不是真實量測。

5. 場上人物對應真實運動明星

data/catalog.json 收錄 241 位運動員（v6 的 60 位、v7 新增 165 位、v7.2 再加 16 位 MLB 明星），每個模式依該運動的名單排出先發，同一場不重複。每位明星有身高／體重（只收錄公開常見數字，查不到者為 null，絕不補造）、慣用手、遊戲能力值（速度、技巧、力量、防守、準確度，為虛構平衡參數）、技術特徵與外觀描述（膚色、髮色、髮型、鬍子、體格、著名配件、號碼）。渲染器依此畫出不同身材與造型，胸前顯示號碼，有授權照片的 60 位以照片當臉。這是風格化近似，不是官方肖像授權；照片授權、來源與各運動名單見 ASSET_CREDITS.html。

要為更多明星加上開放授權肖像：python3 tools/fetch_athlete_photos.py（需網路）會查 Wikidata 的 P18 圖片並只接受 CC BY／CC BY-SA／CC0／公有領域檔案，下載 480px 縮圖並寫入授權資訊；之後執行 bash Upload_SmartAction_Sports.sh --build 重建。

6. 世界場景、Google 地圖與自己的位置

24 個世界場景（高雄、臺北、洛克公園、威尼斯海灘等）照片為平面背景；日光、天氣、季節、氣候、主客場為畫面效果。「定位目前位置」只在您按下時要求權限；「搜尋附近地標照片」向 Wikimedia Commons 查詢 10 公里內的開放授權照片；Google 地圖為一般連結，不需要金鑰。

7. 74 種語言，依瀏覽器與所在地區自動選擇

選擇順序：網址 ?lang=代碼 → 預翻譯入口頁（lang/代碼/）→ 您曾手動選過的語言 → 瀏覽器語言清單 → 依裝置 IANA 時區推測所在地區的主要語言（例如 Asia/Taipei → 繁體中文、Asia/Dhaka → 孟加拉語）→ 英文。不使用 GPS 推測國籍。繁中與英文內嵌於 locales.js，其餘 72 種在切換時從 i18n/代碼.json 載入並由 Service Worker 快取。阿拉伯、希伯來、波斯、烏爾都語為右至左版面。

每種語言 505 個鍵，由生成式模型依英文主鍵翻譯並做完整性驗證；棒球／板球等術語在部分語言以慣用外來語呈現。修改 JSON 後執行 node tools/build_i18n.cjs && node tools/build_languages.cjs。

8. 本機 CPU 生成式 AI 教練（回答學徒問題）

按「載入生成式模型」才會下載 Qwen2.5-0.5B-Instruct ONNX q8（約 546 MB 含執行資源），在您的 CPU 推論，不送到任何伺服器。提示詞已涵蓋 30 種模式的練習要點、本模式規則與本場數據（安打、三振、對拉、桿數、瓶數等），以學徒（初學者）問答為框架；未載入模型時，回覆為固定多語提示並標示「非生成式 AI」。小模型回答可能重複、混用語言或出錯，不是專業訓練評估。

本 zip 不含 512 MB 權重分塊。GitHub 上已有 v6 權重時上傳腳本會自動沿用；本機要離線測試 AI 請執行 python3 tools/fetch_model.py --from "/路徑/v6/SmartAction_Sports" 或 --download。詳見 模型說明。
