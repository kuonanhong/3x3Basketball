Fitxa de l'estrella

Cada figura del terreny de joc es construeix a partir de l'alçada, la complexió i l'estil publicats d'un atleta real; les cares fan servir fotos amb llicència quan n'hi ha. Aproximació estilitzada, no una llicència oficial d'imatge.

Velocitat, habilitat, potència i defensa són valors de disseny del joc, no mesures de les capacitats dels atletes reals.

Les llicències i fonts de les fotos estan disponibles; els atletes i les lligues no avalen aquest projecte.

Controls

Fes servir W/A/S/D per moure't i les fletxes per apuntar. Q salta, E s'ajup, J passa; mantén K per carregar i deixa anar per llançar. Tab canvia de jugador.

Mou-te amb el pad tàctil esquerre i apunta amb el dret. Fes servir els botons de saltar, ajupir-se, passar i llançar.

Mantén el botó de llançament per carregar i deixa'l anar en el moment just. A prop de la cistella, prova una safata o una esmaixada.

Aquest mode recreatiu puntua les cistelles amb 2 o 3 punts; no segueix les regles oficials FIBA 3×3.

Esmaixada: corre sota la cistella, prem Q per saltar i deixa anar K al punt més alt del salt.

Toca o arrossega dins la zona d'strike per moure el bat directament a aquell punt.
