Mga kontrol

Gamitin ang W/A/S/D para gumalaw at mga arrow key para tumutok. Q para tumalon, E para yumuko, J para magpasa. Pindutin nang matagal ang K para mag-ipon ng lakas at bitawan para tumira. Tab para magpalit ng manlalaro.

Gumalaw gamit ang kaliwang touch pad at tumutok gamit ang kanan. Gamitin ang mga pindutan para tumalon, yumuko, magpasa at tumira.

Pindutin nang matagal ang tira para mag-ipon ng lakas, saka bitawan sa tamang oras. Malapit sa ring, subukang mag-layup o mag-dunk.

Libangang laro ito na nagbibigay ng 2 o 3 puntos sa bawat tira; hindi ito sumusunod sa opisyal na FIBA 3×3 na tuntunin.
